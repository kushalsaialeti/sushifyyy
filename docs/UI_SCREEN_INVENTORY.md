# UI screen inventory

All rows represent design-canvas HTML, CSS and simulated state. There are no native implementations in this checkout. The ID prefixes in `design/screens/` identify the screenshots for each row. The source links point to the start of each screen. Every screen needs comparison at 360, 390 and 430 dp, with safe areas, screen-reader order, a 44 dp interactive area, 4.5:1 text contrast and system or in-app reduced motion. The table lists additional checks by screen.
